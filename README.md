# Machine Learning – Beginner to Advanced 🚀

A structured collection of Jupyter notebooks covering Machine Learning from the ground up to advanced techniques.

---

## 📂 Repository Structure

```
.
├── 01_Beginner/
│   ├── 01_Python_for_ML.ipynb          – NumPy & Pandas essentials
│   ├── 02_Data_Visualization.ipynb     – Matplotlib & Seaborn
│   ├── 03_Linear_Regression.ipynb      – Simple & Multiple Linear Regression
│   └── 04_Logistic_Regression.ipynb    – Binary & Multi-class Classification
│
├── 02_Intermediate/
│   ├── 01_Decision_Trees_Random_Forests.ipynb  – Trees, Random Forest, feature importance
│   ├── 02_SVM.ipynb                            – Linear & Kernel SVMs, SVR, GridSearchCV
│   ├── 03_Feature_Engineering.ipynb            – Missing values, encoding, scaling, pipelines
│   └── 04_Model_Evaluation.ipynb               – CV, bias-variance, GridSearch, metrics
│
└── 03_Advanced/
    ├── 01_Neural_Networks.ipynb         – Dense networks with Keras (classification & regression)
    ├── 02_CNN_Image_Classification.ipynb – CNNs, data augmentation, transfer learning
    ├── 03_Ensemble_Methods.ipynb         – AdaBoost, GBM, XGBoost, LightGBM, Stacking
    └── 04_NLP_Basics.ipynb               – TF-IDF, text classification, LSTM sentiment analysis
```

## 📚 Learning Path

| Level | Notebook | Topics |
|-------|----------|--------|
| 🟢 Beginner | 01 Python for ML | NumPy arrays, Pandas DataFrames |
| 🟢 Beginner | 02 Data Visualization | Line, scatter, histogram, heatmap |
| 🟢 Beginner | 03 Linear Regression | OLS, evaluation metrics, residuals |
| 🟢 Beginner | 04 Logistic Regression | Sigmoid, confusion matrix, ROC-AUC |
| 🟡 Intermediate | 01 Decision Trees & RF | Gini, pruning, feature importance |
| 🟡 Intermediate | 02 SVM | Kernel trick, C, gamma, SVR |
| 🟡 Intermediate | 03 Feature Engineering | Imputation, encoding, scaling, pipelines |
| 🟡 Intermediate | 04 Model Evaluation | k-Fold CV, learning curves, tuning |
| 🔴 Advanced | 01 Neural Networks | Dense layers, BatchNorm, Dropout, callbacks |
| 🔴 Advanced | 02 CNN | Conv2D, pooling, augmentation, transfer learning |
| 🔴 Advanced | 03 Ensemble Methods | AdaBoost, GBM, XGBoost, LightGBM, Stacking |
| 🔴 Advanced | 04 NLP Basics | TF-IDF, Logistic Regression, BiLSTM |
